# Manual QA checklist
- [ ] Run `npm run build` and `npm run lint`.
- [ ] Apply migration, add `.env.local`, and create an Auth owner.
- [ ] In two tabs, publish a certificate and confirm its section/navigation appears immediately.
- [ ] Check EN/RU/UZ, system/light/dark, keyboard Escape on a project dialog, chart type controls and mobile drawer at 375px.
- [ ] Send the contact form and confirm the message in admin.
- [ ] Verify draft rows do not return to anonymous users; test seed then clear leaves no published rows.
